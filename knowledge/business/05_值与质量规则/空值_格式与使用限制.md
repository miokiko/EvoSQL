# 缺失值语义

NULL、空字符串、带空格的文本和文字 `无` 为不同存储状态。NULL 不表示未发生或数值零；空字符串不推断填写原因；`无` 不自动转为零。默认保留原值，不静默去空格或合并近义词。计数明确采用物理行、非空值还是不同标识。按具体已定义指标或用户要求使用缺失过滤，不额外缩小案例范围。

# 数值文本

`t_caseinfo.d_rockDelayHour` 和 `t_caseinfo.d_distance` 实为文本，含 `无`、`...` 等值。数值计算仅接收完整可解析的数值，其他原值作为缺失/异常报告，禁止将非法文本转换为 0；没有数值视图时先回答可用数据与限制。

`t_activeinfo.c_energy` 的 `4.986E+06` 与 `4986000.00` 数值上相等：显式数值分析可按科学计数法解析为同值，精确文本查询仍保留两种原值，不默认赋予能量单位。

`t_support.c_supportNum`、`t_supportnew.c_supportNum` 是含单位的工程量描述。不能把根、榀、方等不同单位直接求和；同单位数量提取需完整解析并报告失败记录。

# 时间文本

`t_caseinfo.c_happenDate` 的 39 行全部为有效 `YYYY-MM-DD`，是案例年月统计的默认日期；不能因其他列格式混杂而禁止该字段按年/月统计。

其他时间字段存在 `2016/2/13 0:00:00`、`2016.02.12 00:00:00`、`2017-12-15 14:25`、`12月15日14点25` 等格式。`t_activeinfo.c_time` 是时间描述，不保证完整时间戳。保留精确文本；不自动补充缺失年份、时区，或据不完整文本计算间隔。

# 单位与字段注释限制

- DDL 明确的单位可直接使用：`t_stress.d_size1`、`t_stress.d_size2`、`t_stress.d_size3`、`t_stress.d_kangya`、`t_stress.d_kangla` 为 MPa；三组方位角、倾角为度。主应力注释中的支护列表为误粘贴，已删除。
- `t_stress.d_terrain` 推断为埋深/岩石覆盖厚度，推断单位 m：4 条 2400 均对应锦屏地下实验室，与公开工程深度相符。0 可能为占位；不据此认定所有值为测点精确深度。
- `t_stress.d_strain` 仅保留 DDL 的“变形量”名称，38 条 NULL 和一条 0 无法证明是应变或变形模量，不赋予 GPa。
- `t_activeinfo.d_fate` 推断为累计统计时长，10 条非空记录中 8 条满足事件累计量/事件增速≈该值，独立完整数据组为 4/5；另 2 条的 19/19=1 与该值 9 冲突。对数累计量与增速差也支持时长关系。时间单位未提供，不指定为天或小时。
- `t_activeinfo.c_sumBulk` 同时出现 193000 和 6.13 等值，结合增速存在原量与对数量纲混用迹象，不对整列直接按同一体积单位求和或换算。
- 危害处置时间、爆坑尺寸/体积、飞散距离及部分监测量的单位没有明示。可检索指标含义和原值，不编造单位。
- `t_project.c_totalEvp` 三行均 NULL，仅作为项目 EVP 扩展字段保留，不解释为造价或能量指标。

`knowledge/schema_annotations.json` 记录纠正、推断和无充分依据三类处理。检索文本采用有依据的新解释，推断明确标记；原始 DDL 注释仍保留于不可变快照及结构化 `raw_comment`。外部资料与推断过程见 `docs/DDL_BUSINESS_INTERPRETATION.md`。

# 记录标记

各业务表 `c_mark` 的当前非空观测均为 `1`，DDL 仅称标记。项目将其作为技术标记处理，不默认解释为有效/审核通过，也不添加 `c_mark = '1'` 过滤。明确要求标记值时可按原值查询。

# Schema 收录与业务解释边界

- `t_operaator` 为账号表，排除业务检索；`gale_casefile` 为空且列语义不完整，同样排除。
- `t_activeevent`、`t_activeinfoevent`、`t_waveproperty` 当前为空；收录物理 Schema，能纠正明显注释错字，但不声称有可分析业务记录。
- `t_event` 的 `p1` 至 `p30` 保留物理字段和观测值，缺少定义时不套用指标名或单位。
- 文件路径用于定位附件，不作为业务指标。
